# QoL Suite

32 configurable components in one download; 31 per game.

For **Emerald, FireRed and LeafGreen**. Recommend **gen1recomp 0.3.42+**, especially for Sweet Scent.

- One package with individual switches and original feature options.
- Includes remote services, teleport, daycare, quick healing, capture help, IV views and Scrollable Start Menu.
- Field actions, HM Field Kit with Sweet Scent, bag sorting, battle shortcuts, text/speed settings, party tools, Repels, reusable TMs, shop counts and more.
- Eight Emerald companions: Match Call, Berry Garden, Frontier, Feebas, contests/Pokeblocks, bike switching, daily events and Secret Bases.
- Disable old standalone QoL packages and restart. START > QOL > QOL SETTINGS: A toggles, SELECT opens options, Left/Right pages, B returns.
- 32 components total; 31 per game. Hoenn Tools is Emerald-only; Disable L/R Help is FR/LG-only.

The repository migration changes only package metadata and documentation; runtime Lua matches collection v1.3.
