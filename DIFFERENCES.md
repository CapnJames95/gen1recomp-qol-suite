# Differences from vanilla

32 configurable components in one download; 31 per game.

Supports Ruby, Sapphire, Emerald, FireRed and LeafGreen.

Updates all 32 components for game-appropriate five-game support. Fixes daycare deposits, native text, bag touch actions, bike swapping and Repel handling; Hoenn tools use Ruby/Sapphire’s native facilities.

See [README](README.md) for features, controls and limitations.
